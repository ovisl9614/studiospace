# AGENTS.md

## Commands

- `npm run dev` — dev server (Turbopack, http://localhost:3000); `npm run lint` — ESLint (`eslint-config-next` core-web-vitals + TS); `npm run build` — production build.
- There is no test suite and no `typecheck` script. Run `npx tsc --noEmit` for typechecking; do `lint + typecheck + build` before declaring done.

## Stack quirks (differs from stock create-next-app)

- **Next.js 16 with React Compiler enabled** (`reactCompiler: true` in `next.config.ts`). Do NOT add `useMemo`, `useCallback`, `React.memo`, or manual dependency arrays — the compiler auto-memoizes. Adding `"use client"` is only needed for real interactivity, not memoization.
- **Cache Components are on** (`cacheComponents: true`). Async/request-time data (e.g. `cookies()`, `headers()`) must sit inside a `<Suspense>` boundary — reading them outside one is a build error. Use the `use cache` directive for cacheable data; see `node_modules/next/dist/docs/01-app/` for the current guides.
- **Tailwind v4 with Turbopack** (`@tailwindcss/turbopack` via `next.config.ts`). There is no `tailwind.config.*` — theme tokens and dark-mode variant are defined in `src/app/globals.css` (`@theme inline`, `@custom-variant dark`). Edit CSS variables there, not a config file.
- README claims the app lives in `app/`; it actually lives in **`src/app/`** (`@/*` alias maps to `./src/*`).

## shadcn/ui

- Style is **`base-nova`** (Base UI primitives via `@base-ui/react`, not Radix) — see `components.json`. Don't assume Radix imports or shadcn default styles when editing `src/components/ui/*`.
- To add components run `npx shadcn add <component>` (writes to `src/components/ui/`) instead of hand-rolling.
- Import `cn` from `@/lib/utils` — it re-exports the `cn` npm package (deps include `cn`, not `clsx` + `tailwind-merge`); don't rewrite it. Icons via `lucide-react`.
